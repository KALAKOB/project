# Pharmacy Afterlife (รูมเมทตัวร้ายกับนายตู้ยา) 💊🩺

เกมแนว **Visual Novel เพื่อการศึกษา (Educational Game)** พัฒนาด้วยภาษา **Python (Tkinter)** 
ผู้เล่นจะได้สวมบทบาทเป็นตัวเอกที่ต้องคอยดูแลรูมเมทเด็กสถาปัตย์จอมมึน พร้อมเรียนรู้เรื่องการใช้ยา การปฐมพยาบาล และการใช้ระบบสาธารณสุขในชีวิตประจำวัน

---

## 🌟 จุดเด่นและระบบของเกม

1. **ระบบสร้างและปรับแต่งตัวละคร**: ผู้เล่นสามารถตั้งชื่อตนเองได้ โดยมีบุคลิกสไตล์ "เพื่อนปากร้ายแต่ใจดีและขี้เป็นห่วง" คอยช่วยเหลือนาย "ที" เมทหนุ่มสถาปัตย์ที่นอนน้อยกว่า 5 ชั่วโมงต่อวัน
2. **ระบบการตัดสินใจและผลลัพธ์ (Choices & Consequences)**: ทางเลือกที่ผู้เล่นเลือกจะส่งผลต่อคะแนนความรู้ (Score) และระดับความสัมพันธ์ (Relationship) กับที ซึ่งนำไปสู่บทสรุป/ฉายาตอนจบที่แตกต่างกัน (Rank S, A, B)
3. **มินิเกมอินเทอร์แอคทีฟ**:
   - **มินิเกมตรวจสอบยา**: ตรวจสอบทั้งยาน้ำและยาเม็ด ดูการเสื่อมคุณภาพ และแยกยาที่ยังใช้ได้กับยาที่ต้องทิ้ง
   - **มินิเกมบริหารเงิน (ช้อปปิ้งงบ 1,000 บาท)**: จัดการงบซื้อยาและของใช้เข้าหอตามเช็คลิสต์ ระวังไม่ให้งบบานปลายหรือซื้อแต่ของไร้สาระ
   - **มินิเกมปฐมพยาบาล**: ประเมินระดับแผลน้ำร้อนลวก และเลือกขั้นตอนปฐมพยาบาลทีละขั้น (มีระบบ Game Over หากเลือกวิธีที่ผิดและอันตรายเกิน 2 ครั้ง พร้อมอธิบายสาเหตุ)
   - **มินิเกมจำลองแอปหมอพร้อม**: จำลองหน้าจอสมาร์ทโฟน เพื่อเรียนรู้ขั้นตอนการจองคิวออนไลน์ 4 ขั้นตอนจนได้รับใบนัดหมาย
4. **ระบบบันทึกและโหลดเกม (Save & Load)**:
   - บันทึกเกมอัตโนมัติ (Auto-Save) เมื่อเล่นจบในแต่ละฉาก
   - เมนู Continue เพื่อเล่นต่อจากจุดเดิม และเมนู Load Game
5. **คู่มือความรู้สุขภาพ (In-game Handbook)**: สามารถเปิดอ่านทบทวนความรู้เกี่ยวกับยาสามัญ การเก็บรักษายา การปฐมพยาบาล และการใช้งานแอปหมอพร้อมได้ตลอดเวลาจากหน้าเมนูหลัก

## 📚 องค์ความรู้ในเกม (Educational Content)

### 1. ยาสามัญประจำบ้านและชื่อทางการค้า (2 ชื่อในท้องตลาด)
* **ยาบรรเทาปวด ลดไข้**: พาราเซตามอล (Paracetamol 500 mg) → *ไทลินอล (Tylenol)*, *ซาร่า (Sara)*
* **ยาแก้แพ้ ลดน้ำมูก / ผื่นคัน**: เซทิริซีน (Cetirizine 10 mg) → *ซีร์เทค (Zyrtec)*, *ซีเทค (Cetec)*
* **ยาฆ่าเชื้อ ใส่แผลสด**: โพวิโดน-ไอโอดีน (Povidone-Iodine 10%) → *เบตาดีน (Betadine)*, *โพวิโดน โพลีฟาร์ม*
* **ผงน้ำตาลเกลือแร่ (ท้องเสีย)**: โออาร์เอส (ORS) → *รอยัล ดี (Royal-D)*, *ดี-ไลท์ (D-Lyte)*
* **ยาลดกรด เคลือบกระเพาะ / ขับลม**: อลูมิเนียมไฮดรอกไซด์ + แมกนีเซียมไฮดรอกไซด์ + ไซเมทิโคน → *แอนตาซิล (Antacil)*, *แอร์-เอ็กซ์ (Air-X)*

### 2. วิธีตรวจสอบยาที่เสื่อมคุณภาพ และการเก็บรักษาที่ถูกต้อง
* **ยาเม็ด**: สีเปลี่ยน มีจุดด่าง บวม แตกหัก ร่วนเป็นผง ชื้น หรือกลิ่นเปลี่ยนไป
* **ยาแคปซูล**: เปลือกนิ่ม เหนียวติดกันเป็นก้อน ปริแตก หรือผงยาข้างในแข็ง
* **ยาน้ำ**: ตกตะกอนแข็งเขย่าไม่ละลาย แยกชั้น กลิ่นบูด เปรี้ยว หรือมีเชื้อรา
* **ยาครีม/ขี้ผึ้ง**: แยกชั้นของน้ำมันกับเนื้อครีม กลิ่นเหม็นหืน เนื้อหยาบ
* **การเก็บรักษา**: เก็บในที่แห้ง อุณหภูมิห้องปกติ (< 25-30°C) พ้นจากแสงแดด ไม่เก็บในห้องน้ำ (ความชื้นสูง) และไม่เก็บในตู้เย็นเว้นแต่มีระบุไว้บนฉลาก

### 3. วิธีปฐมพยาบาลเบื้องต้นจากน้ำร้อนลวก และความเชื่อผิดๆ
* **ระดับแผล**: แผลน้ำร้อนลวกที่มีตุ่มน้ำพองใสและปวดแสบร้อนคือ **แผลระดับที่ 2 ชนิดตื้น (Superficial Second-degree Burn)**
* **ขั้นตอนปฐมพยาบาลที่ถูกต้อง**:
  1. ล้างหรือแช่แผลด้วย**น้ำสะอาดอุณหภูมิห้อง**นาน 10-15 นาที เพื่อลดความร้อนสะสม
  2. **ห้ามเจาะตุ่มน้ำพองใสเด็ดขาด** เพราะตุ่มน้ำช่วยป้องกันการติดเชื้อ
  3. ปิดแผลหลวมๆ ด้วย**ผ้าก๊อซสะอาด**หรือผ้าสะอาด ไม่ใช้สำลี และไม่รัดแน่น
* **ความเชื่อที่ผิดและอันตราย**:
  - ทายาสีฟัน, น้ำปลา, น้ำมัน, แป้ง (เสี่ยงติดเชื้อรุนแรง ล้างออกยาก)
  - ประคบน้ำแข็งโดยตรง (ทำให้หลอดเลือดหดตัว เนื้อเยื่อขาดเลือดและตายเพิ่ม)
  - นำว่านหางจระเข้สดที่ยังไม่ล้างยางเหลืองมาโปะ (ยางทำให้ระคายเคือง)

### 4. ขั้นตอนการใช้งานแอป "หมอพร้อม"
1. เข้าสู่หน้าหลัก กดเลือก **"นัดหมายออนไลน์"**
2. เลือก **"จองคิวหมอ"**
3. ระบุข้อมูลการนัดหมาย (จังหวัด, เขต/อำเภอ, โรงพยาบาล, แผนก, วันที่, แพทย์ [เลือกไม่ระบุได้], เวลา, อาการเบื้องต้น, รูปแบบบริการ)
4. ยืนยันการจอง และ ตรวจสอบ **"ใบนัดหมาย"**
